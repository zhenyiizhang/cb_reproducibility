# Zebrafish runtime bundle

This directory contains the minimal zebrafish runtime assets required by the public zebrafish downstream notebook and CLI.

Included components:

- `config/zebrafish_1111.yaml`
- `data/zebrafish_1108_with_annotation.csv`
- `edge_classifier/zebrafish.pt`
- `results/zebrafish_1111/`
- `results/zebrafish_all_figures/focus_anchor/classifier_cache/`
- `results/zebrafish_all_figures/lr_scores/`
- `results/zebrafish_all_figures/lr_single_timepoint/`
- `results/zebrafish_all_figures/gene_pathway/figures/`
- `results/zebrafish_all_figures/zebrafish_ablation_yolk/trajectory/frames/`
- `results/zebrafish_all_figures/zebrafish_ablation_evl_blackbox/trajectory/frames/`

The bundle intentionally omits unrelated large datasets.
